Three steps, one afternoon

The whole job is getting a list of names into a shape you can hang by the door. TIKTAK does that and stops.

Paste your spreadsheet

Copy the columns straight out of Excel or Google Sheets. TIKTAK works out which column is which, expands “Cohen, 4” into four guests, and flags anyone listed twice.

Say who can’t sit together

Two rules — must sit with, must not sit with. A table that breaks one turns red the moment it does, so you find out while you are looking at it.

Print the chart

A floor plan, a list for every table, and an alphabetical index of every guest with their table number. Real text in a real PDF, sharp at any size.

Questions people actually ask

Where is my guest list stored?
In your browser, on your own device. There is no account and no server to send it to — TIKTAK has no database at all. The only network requests it ever makes are a licence check when you activate Pro, and a privacy-friendly page counter.
What happens if I clear my browser?
You lose the plan, the same way you would lose an unsaved document. Use Project → Export project file to save a copy you can keep. That file is the backup.
Can I work from two computers?
Yes, through the project file: export it on one machine, open it on the other. There is no live sync, because that would need the server TIKTAK deliberately does not have.
Is this a subscription?
No. $19 once, for good. Planning — guests, tables, constraints, auto-arrange and CSV export — is free and unlimited whether you ever pay or not.
How many guests can it handle?
Unlimited on both tiers. It is built and tested against a thousand guests, which is well past the point where most venues run out of room.
Does it work on a phone?
You can view a plan and export from a phone. Arranging a room really wants a bigger screen, so on a small one TIKTAK opens read-only rather than pretending otherwise.
